# 🚀 Cosmic Trader

**A strategic card-based survival game built for the Bath Game Jam 2026.**

## 🌌 The Theme: "Out of this World"
Your ship has broken down in deep space! To survive, you must navigate the cosmos, trade with bizarre alien species, and fend off space pirates. Your ultimate goal is to collect **3 Warp Cores** to jump-start your ship and make it back to Earth.

## 🎮 How to Play
You start with **10 Space Credits** and **5 Scrap Metal**. Every turn, you draw a card that presents a new encounter:
- **Alien Merchants:** Offer fair (or unfair) trades for resources.
- **Space Pirates & Hazards:** Force you into high-stakes choices. Pay them off to stay safe, or fight back and suffer the consequences!
- **Lucky Events:** Find floating debris or salvage derelict ships for free resources.

**Win Condition:** Collect 3 Warp Cores to escape!  
**Lose Condition:** If both your Credits and Scrap hit 0, you are stranded in space forever.

## ✨ Features
- **Strategic Resource Management:** Balance your Credits, Scrap, and Warp Cores carefully.
- **Dynamic Encounters:** 12 unique cards with varying costs, rewards, and punishments.
- **Risk vs. Reward Mechanics:** Pirate cards force you to make tough decisions under pressure.
- **Ship's Log:** A real-time scrolling journal that records every decision you make on your journey.
- **Polished UI:** Beautiful deep-space theme, glowing effects, and smooth CSS animations.
- **Fully Responsive:** Playable on desktop and mobile browsers.

## 🛠️ Tech Stack
Built entirely with modern, lightweight web technologies:
- **React 19:** For robust state management and a seamless single-page application experience.
- **Vite:** For blazing-fast development and optimized production builds.
- **Tailwind CSS v4:** For rapid, beautiful styling and custom animations without writing custom CSS files.

## 🚀 How to Run Locally

Want to play or check out the code? Follow these steps:

1. Clone the repository:
   git clone https://github.com/JefCristo/cosmic-trader.git
   cd cosmic-trader

2. Install dependencies:
   npm install

3. Start the development server:
   npm run dev
   Open your browser and navigate to http://localhost:5173.

4. Build for production:
   npm run build
   npm run preview
